# Запись измерений — Android prototype

Небольшое офлайн-приложение для записи временных отметок на реальном Android-устройстве и экспорта CSV.

## Что записывается
- индекс измерения;
- отметка `SystemClock.elapsedRealtimeNanos()`;
- разница между соседними отметками в наносекундах;
- результат небольшой детерминированной программной операции;
- модель устройства и версия Android.

## Ограничение
Это реальные программные замеры времени, но не захват каждого физического такта CPU и не внутреннего состояния процессора. Android-приложение без специальных привилегий не имеет такого доступа.

## Получить APK
После запуска GitHub Actions workflow **Build Tick Recorder APK** откройте вкладку Actions репозитория, выберите успешный запуск и скачайте artifact `tick-recorder-debug-apk`. Это debug APK для ручной установки; Android может попросить разрешить установку из выбранного источника.

## Сборка локально
Нужны JDK 17+, Android SDK platform 35 и Gradle 8.9+:
```sh
cd tick-recorder
gradle assembleDebug
```
